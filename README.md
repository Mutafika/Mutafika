# Mutafika

Solo dev. I build my own tools end-to-end — DBs, GUI frameworks, languages, apps — mostly in Rust, mostly for myself first.

## Stack

**Systems / core**
- Rust — daily driver. Everything from DB engines to GUI to TUI.
- C ABI / FFI when something needs to embed elsewhere.
- TypeScript — for web frontends and Node bindings only.

**Frontend**
- Next.js + Tailwind for web apps.
- Sabitori (my own wgpu GUI framework) for native desktop apps.
- Flutter for mobile.

**Data**
- Enchu DB — my own columnar/cylinder DB engine. Powers most of my stack.
- Postgres / SQLite when the project demands a standard.

**Infra**
- Cloud Run, Firebase, Cloudflare for the few projects that go online.
- Self-host where I can.

**Workflow**
- Claude Code as my daily AI pair / dev agent.
